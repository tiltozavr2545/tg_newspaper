## Известные ограничения, зафиксированные до старта разработки

- **Запуск — по кнопке в локальной консоли, не по расписанию.** Нет ни будильника, пробуждающего ПК, ни автозапуска, ни автовыключения по завершении. Пользователь сам открывает консоль (`uv run python scripts/console.py`) и нажимает "Собрать газету" когда захочет; тот же прогон доступен и из терминала (`uv run tg-newspaper`) для headless-запуска без браузера. Период сбора при этом всегда фиксированные последние 24 часа **от момента нажатия кнопки**, не "с последнего успешного прогона" — наверстывание пропущенных запусков сознательно не реализуется, каждый прогон просто берёт свои последние сутки.
- **Доступ к каналам — MTProto под пользовательским аккаунтом (Telethon), не Bot API.** У ботов нет метода "отдай историю канала за период" — они получают посты только по мере появления (`getUpdates`/webhook), пока подключены. Это несовместимо с механикой агента: сбор должен уметь по требованию отдать историю канала за произвольный период "с этого момента назад", а не только слушать новые сообщения. MTProto умеет отдать историю по запросу — это и есть решающая причина выбора, а не просто предпочтение. Подробности — "Почему MTProto, а не Bot API" в [README.md](README.md) и раздел "Сбор постов" в [docs/project-brief.md](docs/project-brief.md).
- **Сессия Telethon — это ключ к Telegram-аккаунту, а не токен с ограниченными правами.** Хранить как секрет, не коммитить в репозиторий и не логировать. Аккаунт — отдельный, заведённый специально под проект, не основной личный: утечка сессии компрометирует только его.
- **Принтер (HP Color LaserJet Pro MFP M377dw) печатает только по локальной сети.** Облачная печать для этой модели физически недоступна: HP закрыла сервис ePrint в январе 2023 года (переставала выпускать его на новых принтерах ещё в 2020-м), Google Cloud Print закрыт Google ещё раньше, в конце 2020-го. Печатающий код обязан выполняться в той же локальной сети, что и принтер (AirPrint/CUPS/IPP) — вариант с облачным рендером и печатью по email для этого принтера не работает и не будет работать.

## Проект

Пилотный проект: идея — заменить утренний скроллинг ленты печатным газетным номером фиксированного объёма (4 альбомные полосы A4), который агент собирает и печатает сам, без участия человека. Рендер — HTML/CSS + Playwright/Chromium (`src/tg_newspaper/layout.py`); что не помещается в номер, LLM-оценка значимости (`classifier.py`) решает сократить нейронкой или выбросить, а не печатать как попало. Работать по этапам из implementation-plan.md, не забегая вперёд открытых вопросов из future-development.md.
